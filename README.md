# praktika-p1-blin-krasniqi
Projekti i pare praktike-Shkolla Digjitale Lipjan

Ky eshte nje editim i bere nga Visual Studio Code 

Komandat me te perdorura te Github:

mkdir emri-folderit // per te ndertuar nje folder

type nul > index.html // per te ndertuar nje file

git switch -c development // per te krijuar nje branch new branch

git switch development // me kalu ne branch Development

git switch -c feature/login // krijon nje feature Brenda branch development

git pull --ff-only origin development // me i marre ndryshimet e fundit te bera nga GitHub ne pc tone 

git restore README.md // kthen prapa ndryshime te bera paraprakisht

git config init.defaultBranch main //percakton default main branch 

git remote -v // shikon me cilin repository eshte i lidhur

git remote set-url origin linku i repository // me ndryshu repository
